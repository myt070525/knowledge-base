## 开发规范

### 提交信息约定

采用约定式提交（Conventional Commits），中文描述：

| 前缀 | 含义 |
| --- | --- |
| `feat:` | 新功能 |
| `fix:` | 缺陷修复 |
| `docs:` | 文档变更 |
| `refactor:` | 重构 |
| `test:` | 测试相关 |
| `chore:` | 构建、依赖、配置等杂项 |

示例：

```
feat: 实现知识条目全文检索接口
docs: 补充需求分析文档
```

### 分支约定

- `main`：稳定分支，始终保持可运行
- `dev`：日常开发集成分支
- `feature/xxx`：单个功能分支
