## 3. 每阶段详细拆解

### 阶段 0（10 月，4 周）打地基

**学什么**
- HTML / CSS 快速过一遍（不用深，够用就行）
- JavaScript 核心：变量、函数、数组对象、`map`/`filter`、**Promise / async-await**
- ES6+：解构、模板字符串、模块 `import/export`、箭头函数
- 命令行基础、VS Code 使用
- **Git 协作**：`clone` / `branch` / `add` / `commit` / `push` / `pull` / **解决冲突**

**项目上做什么**
- 加入团队仓库，建自己的分支
- 把你的学习笔记/练习代码提交上去

**验收标准**
> 你能独立完成：克隆仓库 → 建分支 → 改文件 → 提交 → 推送 → 发 PR，全程不看教程。

**⚠️ 重点**：Git 是五人协作的命脉。分工文档里明确写了"代码不丢失、不冲突"。
**这个阶段偷懒，后面一定出事故。**

---

### 阶段 1（11 月，4 周）Vue3 核心

**学什么**
- Vue3 **组合式 API**：`setup`、`ref`、`reactive`、`computed`、`watch`
- 组件化：父子传参 `props` / 事件 `emit`、插槽 `slot`
- 生命周期、条件渲染 `v-if`、列表渲染 `v-for`
- **Vue Router**：页面路由、动态路由
- **Element Plus**：表单、按钮、输入框、卡片、表格、消息提示

**项目上做什么**
- 搭出问答界面的**静态骨架**：
  - 输入框 + 发送按钮
  - 答案展示区（先用写死的假数据）
  - 引用来源卡片
- 再把评测看板做个静态页面骨架

**验收标准**
> 打开页面，能输入问题、点按钮，下方显示一段**写死的**答案和来源卡片。
> 页面能通过路由在两个页面之间切换。

**学习方法**：以 [Vue3 官方中文文档](https://cn.vuejs.org/) 为主。别一开始就看长视频课。

---

### 阶段 2（12 月，4 周）数据交互

**学什么**
- `async/await` + `try/catch` 错误处理
- **Axios**：`get`/`post`、请求拦截器、响应拦截器
- **Mock 数据**：后端没写完时，自己造假数据先跑通
- Vite 的 `server.proxy` 解决开发期跨域
- 环境变量 `.env` + `import.meta.env.VITE_API_BASE`

**项目上做什么**
- 封装一个 `src/api/` 目录，把接口调用集中管理
- 用 Mock 数据跑通完整问答流程
- **主动找后端同学定接口契约**（见 [03-前端角色地图](03-前端角色地图.md) 第 3 节）
- 后端接口一旦就绪，把 Mock 换成真接口

**验收标准**
> 输入问题 → 前端发出真实 HTTP 请求 → 后端返回 → 页面渲染答案。
> 请求失败时页面显示友好错误提示，而不是白屏。

> 💡 **这一阶段的主动权在你**。别等后端。拿契约 + Mock，你就能独立推进。

---

### 阶段 3（1 月，4 周）流式输出 + 多轮会话 ← 你的技术亮点

> 寒假期间（1 月中~2 月中）时间充裕，把这阶段做扎实。

**学什么**
- **SSE（Server-Sent Events）**：`EventSource` / `fetch` + `ReadableStream`
- `TextDecoder` 处理中文分块（防止半个汉字乱码）
- **Pinia** 状态管理：全局会话状态、历史记录
- 组件间复杂通信

**项目上做什么**
- 答案**逐字出现**（打字机效果）
- 多轮对话：保留上下文，能追问
- 左侧会话历史列表，可切换、可删除
- 加载态、停止生成按钮

**验收标准**
> 现场提问，答案一个字一个字蹦出来，中途能点"停止"。
> 追问"那刚才那个问题里的 X 呢"，模型能接上文。

> 🔥 这是评委最直观感受"这系统是活的"的地方，**做出来就是加分项**。

---

### 阶段 4（2 月，4 周）评测可视化看板 ← "复杂前端"的核心

**学什么**
- **ECharts**：柱状图、折线图、雷达图、热力图、散点图
- 图表容器尺寸、`resize` 自适应、`dispose` 释放
- 数据驱动：从 JSON 生成图表配置
- 组件复用与封装（一个图表组件吃不同数据）

**项目上做什么**
- 直接拿**真实评测数据**练手：`runs/*/*.metrics.json`
- 做四个层次（详见 [03-前端角色地图](03-前端角色地图.md) 第 2 节）：
  1. 模型 × 任务组 分组柱状图（对应论文 Table 4）
  2. 提示策略 × 任务组 热力图（对应论文 Table 5）
  3. 单任务下钻 + 指标表
  4. 单题明细表格（分页、可搜索、高亮对错）

**关键设计原则**（容易做错，记住）
> **不同题型的量纲不同**：闭集是 Acc(0~100)、开放题是 LLM 打分(1~5)。
> **绝不能**混在一张图里比大小。要**分任务组做小图**。

**验收标准**
> 打开看板，能复现论文 Table 5 的规律：
> "Few-shot-CoT 在多数任务上最好，Few-shot Role 在多选题上最强"——
> 而且是一眼从图上**看出来**的，不是读表格读出来的。

---

### 阶段 5（3 月，4 周）整合打磨

**做什么**
- 前后端**全链路联调**（前端 → 后端 → RAG → 大模型）
- UI 美化：统一配色、间距、响应式（评委可能用投影仪，注意字号）
- 性能：首屏加载、图表渲染速度
- 兜底：网络断了、模型挂了、后端 500 了，页面都不能白屏
- 准备一个**演示脚本**：点哪里、问什么、展示什么

**验收标准**
> 在一台"干净"的电脑上，按 README 步骤能跑起来整套系统。

---

### 阶段 6（4 月，3 周）交付

**做什么**
- 录演示视频（一般要求 5~10 分钟）
- 写设计文档 / 使用说明
- 答辩 PPT（**前端部分**：技术选型理由、界面截图、遇到的难点怎么解决）
- 代码冻结（4 月 10 日）→ 之后只修 bug
- 提交前按比赛要求逐项核对材料

**验收标准**：材料齐全，按时提交。

## 4. 每周节奏建议

假设每周投入 **10~12 小时**（工作日每天 1 小时 + 周末 5 小时）：

| 时段 | 内容 |
| --- | --- |
| 工作日 | 每天 1h：看文档 / 写小练习 |
| 周六 | 3h：项目实战（写真代码） |
| 周日 | 2h：复盘 + 补漏 + 提交 Git |

**关键原则**：**每周必须有代码产出并提交**。
不是"看完了教程"，而是"这周页面多了一个能点的功能"。

## 5. 学习方法（少走弯路）

| 建议 | 原因 |
| --- | --- |
| **官方文档 > 视频课** | Vue/Element Plus/ECharts 中文文档质量极高，查得快、不过时 |
| **不要刷课，要写** | 看 10 小时视频不如自己写 2 小时 |
| **先跑通再理解** | 配置类的东西先照抄跑通，再回头搞懂为什么 |
| **每学一个知识点，就用到项目上** | 立刻产生价值，也记得牢 |
| **遇到 bug 先自己查 30 分钟** | 再问人/AI。这个能力就是答辩底气 |
| **善用 AI 但要读懂** | 见下方红线 |

## 7. 三条红线

分工文档原文：**"不能只靠 AI 生成代码，必须看懂并能独立修改自己的代码"**。

具体说：

1. **红线一**：AI 生成的代码，你必须能逐行讲清楚在干什么。讲不清就删了重写。
2. **红线二**：不要一次性让 AI 生成整个项目。按小功能生成，每个都读懂。
3. **红线三**：Git 提交历史要是真实开发过程，不要最后一次性全推上去。

> 现场演示时评委可能会让你"改个小地方试试"。这时候能不能改，就是真本事。

## 8. 本周就做的三件事

### ① 建 Vue3 项目（约 15 分钟）

```powershell
cd D:\            # 或你习惯放代码的地方
npm create vue@latest my-agriqa-frontend
# 提示选项时：Router 选 Yes，Pinia 选 Yes，其余先选 No
cd my-agriqa-frontend
npm install
npm run dev
```

浏览器打开提示的地址（通常是 `http://localhost:5173`），看到 Vue 欢迎页就成功了。

### ② 装三个必备库

```powershell
npm install element-plus echarts axios
```

### ③ 用真实数据画第一个图

1. 复制 `E:\A.软工比赛项目：知识库\runs\demo_zero_shot\qwen3_8b_llamacpp_local_zero_shot_test.metrics.json`
   到新项目里；
2. 用 ECharts 把它画成一个柱状图；
3. 提交到你的 Git 仓库。

做完这三步，你就已经**摸到真实项目**了。
